# Duo

Start the same Netflix / Prime movie on two devices at the same moment, each with its own headphones.

1. Install `Duo.ipa` (from Releases) on both devices with Sideloadly.
2. Open Duo on both. They find each other.
3. Paste the movie link on one device, tap **Start** on either.
4. Both open the movie, then both play a short cue sound from the speaker at the same instant. Switch Control hears it and taps Play.

The one-time setup (Switch Control sound switch + recipe, Shortcuts automation) is in the app under Settings.
